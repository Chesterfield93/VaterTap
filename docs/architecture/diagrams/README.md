# Diagramme

Je Diagramm Quelle (`.drawio`) und Export (`.svg`) mit gleichem Basisnamen.
Beim drawio-Export "Include a copy of my diagram" aktivieren.
Export immer im selben Commit wie die Quelle aktualisieren.

Geplant:

- `system-overview` - Knoten, Peripherie, Schnittstellen (Aktualisierung ausstehend)
- `brain-tasks` - hexagonaler Aufbau und Task-/Kernzuordnung
- `pour-sequence` - Check-in bis Buchung und Sync
