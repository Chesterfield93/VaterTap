# ADR-0013: OTA-Updates

- Status: accepted (Signierung und Bundle offen)

## Entscheidung

- Brain und Display per OTA, Zwei-Partitionen-Schema mit Rollback
- Brain: Heimnetz und mobile Hotspots; Display: nur Heimnetz
- Bis Signierung: OTA nur im bewusst aktivierten Wartungsmodus
- Koordination zunaechst manuell

## Offen

- **Signierung:** Public Key in Firmware, signierte Images, Rollback-Sperre. Erst dann
  ist die Quelle (Backend oder GitHub Releases per Pull) sicherheitlich egal.
- **Bundle-Update:** Neue Firmware auf beiden Knoten in die inaktive Partition schreiben,
  Bootwechsel erst nach Abstimmung beider Knoten. Voraussetzung: Protokollversion
  abwaertskompatibel fuer mindestens eine Version.

## Konsequenz

Protokollversion in jeder UART-Nachricht (ADR-0010).
